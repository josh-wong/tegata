このページでは、Tegata がデータをどのように処理するか、およびプロジェクトメンテナーの責任の限界について説明します。

## プライバシー

Tegata はデバイス上で完全に動作するように設計されています。テレメトリーを収集せず、いかなる種類の分析データも送信しません。

TOTP/HOTP コードの生成、チャレンジ・レスポンスの署名、スタティックパスワードの取得などのすべての認証操作はローカルで行われます。認証コード、パスワード、チャレンジレスポンス、ボールトの内容は外部サーバーに送信されることはありません。

Tegata が行う唯一のネットワークアクティビティは、自分のマシンの Docker で実行されているか、自分で設定したリモートサーバー上の[ScalarDL Ledger](https://scalardl.scalar-labs.com/docs/)インスタンスとのオプションの gRPC 通信です。そのような場合、この通信はローカルネットワーク上に留まるか、リモートサーバーに送信されます。監査ログを有効にしていない場合、Tegata はネットワーク接続を一切行いません。

監査ログが記録する内容と監査データの保存方法の詳細については、[監査ログのセキュリティとプライバシー](security-best-practices.mdx#監査ログのセキュリティとプライバシー)を参照してください。

## 免責事項

Tegata は現状のまま提供され、明示または黙示を問わず、いかなる保証も行いません。開発者およびプロジェクトメンテナーは以下について責任を負いません。

- ボールトファイルの破損、パスフレーズの忘却、または USB ドライブの紛失による**データの損失**。
- ボールトに保存されたクレデンシャルへの不正アクセスによる**セキュリティ侵害**。
- ScalarDL Ledger のデプロイに関連するコストを含む、Tegata の使用から発生する**費用**。
- このソフトウェアの使用または使用不能から生じる**直接的、間接的、偶発的、または派生的な損害**。

Tegata の使用は自己責任で行ってください。ボールトとクレデンシャルを保護するために[セキュリティのベストプラクティス](security-best-practices.mdx)のガイダンスに従ってください。

完全なライセンステキストについては、[MIT ライセンス](https://github.com/josh-wong/tegata/blob/main/LICENSE)を参照してください。
