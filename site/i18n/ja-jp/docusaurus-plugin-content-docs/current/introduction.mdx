Tegata (手形) は、標準的な USB ドライブまたは microSD カードに暗号化されたクレデンシャルを保存するオープンソースのポータブル認証システムです。名前は歴史的な日本の旅行証明書 (手形) に由来しています。手形とは、手形の押印によってポータブルな身分証明として使用された文書のことです。タグラインは「あなたの認証履歴。整合性が確認された。」です。

## Tegata が解決する問題

多くの認証アプリは、クレデンシャルを特定のスマートフォンやクラウドアカウントに紐づけています。Tegata は、物理的に携帯しているハードウェアにクレデンシャルを保存します。これは、ハードウェアレベルの鍵の分離なしにポータビリティとオプションの監査可能性を必要とする個人にとって、専用のハードウェアセキュリティキー (YubiKey など) に代わる低コストの選択肢です。

## Tegata の機能

Tegata は4種類のクレデンシャルタイプをサポートしています。

- **TOTP および HOTP:** RFC 6238 または RFC 4226 に準拠したサービスと互換性のある、時間ベースおよびカウンターベースのワンタイムパスワード
- **チャレンジ・レスポンス:** サポートするサービス向けの HMAC-SHA256 署名
- **スタティックパスワード:** オンデマンドで取得する暗号化されたパスワード

クレデンシャルは USB ドライブ上のボールトファイルに保存され、選択したパスフレーズを使用して AES-256-GCM で暗号化されます。すべての認証はローカルで行われ、クラウドサービスへは何も送信されません。

## オプションの監査ログ

Tegata は、すべての認証イベントを[ScalarDL Ledger](https://scalardl.scalar-labs.com/docs/) によるバックエンドを持つ改ざん防止ハッシュチェーン監査ログに記録できます。監査ログはデフォルトで無効になっており、有効にするには Docker が必要です。
