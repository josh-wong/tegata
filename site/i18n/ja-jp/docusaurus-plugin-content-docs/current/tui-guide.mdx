Tegata には、個別の CLI コマンドよりもキーボード駆動のビジュアル操作を好むユーザー向けのインタラクティブなターミナルユーザーインターフェース (TUI) が含まれています。TUI はアイドルタイムアウトベースの自動ロックでセッションを維持するため、ボールトを一度アンロックするだけでセッション全体でコードを生成できます。

ターミナルで以下のコマンドを実行して TUI を起動します。

```bash
tegata ui
```

## 初回起動とセットアップウィザード {#初回起動とセットアップウィザード}

解決されたボールトパスにボールトが存在しない場合、TUI はセットアップウィザードを起動します。ウィザードは `tegata init` と同じ手順 (パスフレーズの選択、ボールトの作成、リカバリーキーの表示) を案内します。

:::danger[リカバリーキーを保存してください]

リカバリーキーはウィザードの最後に一度だけ表示されます。続行する前に書き留めて、USB ドライブとは物理的に別の安全な場所に保管してください。

:::

セットアップが完了すると、ウィザードは自動的にメインビューに移行します。

## ボールトのアンロック

ボールトがすでに存在する場合、TUI は起動時にアンロックプロンプトを表示します。

```
┌─ Tegata ─────────────────────────────────────────────────────────────────────┐
│                                                                              │
│                         ボールトのパスフレーズを入力してください:                   │
│                         [ _________________ ]                                │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

パスフレーズを入力して **Enter** を押します。パスフレーズはマスクされています (表示されません)。3回の失敗後、Tegata は指数バックオフを適用し、次の試行が許可されるまでの待機時間を表示します。

## メインビュー

アンロック後、メインビューには2パネルのレイアウトが表示されます: 左側にクレデンシャルリスト、右側に詳細パネル。

```
┌─ Tegata ────────────────────────────────────────────────────────────────────┐
│ ┌── Credentials (3) ──────────┐ ┌── GitHub ──────────────────────────────── │
│ │ > GitHub             totp   │ │                                           │
│ │   AWS-prod           hotp   │ │   482901                                  │
│ │   WiFi-office        pw     │ │   Expires in 18s  ████████░░░░  (18/30)   │
│ │                             │ │                                           │
│ │                             │ │   ✓ Copied to clipboard                   │
│ │                             │ │     (auto-clear in 45s)                   │
│ │                             │ │                                           │
│ └─────────────────────────────┘ └────────────────────────────────────────── │
│  [↑↓] ナビゲート  [Enter] コピー  [a] 追加  [r] 削除  [q] 終了              │
└─────────────────────────────────────────────────────────────────────────────┘
```

左パネルにはすべてのクレデンシャルがタイプの略称 (`totp`、`hotp`、`pw`、`cr`) とともに表示されます。右パネルには選択されたクレデンシャルの現在のコードまたはアクション結果が表示されます。

## キーボードショートカット {#キーボードショートカット}

TUI は、クレデンシャル間の移動、クレデンシャルの管理、オーバーレイやダイアログとのインタラクションのためのキーボードナビゲーションをサポートしています。クレデンシャルのナビゲートやコードのコピーなど、最も一般的な操作には矢印キーを使用します。

### ナビゲーション

これらのキーを使用してクレデンシャルリストを移動し、セッションを管理します。

| キー | アクション |
|-----|--------|
| `↓`または`j` | 選択を下に移動 |
| `↑`または`k` | 選択を上に移動 |
| `Enter` | 選択されたクレデンシャルのコードまたはパスワードをコピー |
| `q` | 終了 (ボールトが自動ロックされます) |

選択はループします: 最初のクレデンシャルで `↑` / `k` を押すと最後に移動し、最後のクレデンシャルで `↓` / `j` を押すと最初に移動します。

### クレデンシャル管理

これらのキーを使用して TUI 内から新しいクレデンシャルを追加し、既存のクレデンシャルを削除します。

| キー | アクション |
|-----|--------|
| `a` | クレデンシャル追加オーバーレイを開く |
| `r` | 選択されたクレデンシャルの削除確認ダイアログを開く |

### オーバーレイとダイアログ内

クレデンシャルを追加または削除する際は、これらのキーを使用してフィールドをナビゲートし、アクションを確認します。

| キー | アクション |
|-----|--------|
| `Tab` | フィールドまたはオプションを切り替え |
| `Enter` | 確認 / 送信 |
| `Esc` | キャンセルしてメインビューに戻る |
| `y` | 確認 (はい/いいえのプロンプトで) |
| `n` | キャンセル (はい/いいえのプロンプトで) |

## クレデンシャルの追加

メインビューで `a` を押してクレデンシャル追加オーバーレイを開きます。

```
┌─ Tegata ────────────────────────────────────────────────────────────────────┐
│ ┌── Credentials (3) ──┐ ┌── GitHub ──────────────────────────────────────── │
│ │ ┌─ Add credential ────────────────────────────────┐                       │
│ │ │                                                 │                       │
│ │ │  Type:    [TOTP]  HOTP   CR   Static            │                       │
│ │ │                                                 │                       │
│ │ │  Label:   <label input>                         │                       │
│ │ │  Secret:  <secret input, masked>                │                       │
│ │ │                                                 │                       │
│ │ │  [Tab] タイプ切替  [Enter] 追加  [Esc] キャンセル   │                       │
│ │ └─────────────────────────────────────────────────┘                       │
│ └─────────────────────┘ └────────────────────────────────────────────────── │
│  [j/k] ナビゲート  [Enter] コピー  [a] 追加  [r] 削除  [q] 終了                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

`Tab` を押してクレデンシャルタイプ (`TOTP`、`HOTP`、`CR`、`Static`) を切り替えます。ラベルとシークレットフィールドに入力してから `Enter` を押して保存します。保存せずにキャンセルするには `Esc` を押します。

クレデンシャルが正常に追加されると、オーバーレイが閉じられ、新しいクレデンシャルがリストに表示されて自動的に選択されます。

## クレデンシャルの削除

削除したいクレデンシャルに移動して`r`を押します。確認ダイアログが表示されます。

```
│  ┌─ クレデンシャルを削除しますか？ ──────────────┐
│  │                                          │
│  │  クレデンシャル 'GitHub' を削除しますか？     │
│  │  この操作は元に戻せません。                  │
│  │                                          │
│  │  [y] はい、削除する  [n] キャンセル          │
│  │                                          │
│  └──────────────────────────────────────────┘
```

誤って削除しないようにクレデンシャル名がダイアログに表示されます。デフォルトのアクションは**キャンセル** (`n`) です。`y` を入力して削除を確認します。

削除後、サイドバーはすぐに更新され、選択は次のクレデンシャルに移動します。最後のクレデンシャルが削除された場合、詳細パネルには空のボールトプロンプトが表示されます。

## TOTP カウントダウンタイマー {#totpカウントダウンタイマー}

TOTP クレデンシャルの場合、詳細パネルにはプログレスバーと残り秒数が表示されます。

```
   482901
   Expires in 18s  ████████░░░░  (18/30)
```

バーはウィンドウが期限切れになるにつれて減少します。コードが変わると、新しいコードと新しいタイマーが自動的に表示されます。`Enter` を再度押す必要はありません。表示はその場で更新されます。

## 自動ロックの動作 {#自動ロックの動作}

TUI は5分間の非アクティブ後 (`tegata.toml` で設定可能) に自動ロックします。ロックされると、アンロックプロンプトが再表示されます。セッション状態 (選択されていたクレデンシャル) は同じセッション内のロック/アンロックサイクルを通じて保持されます。

アイドルタイムアウトを変更するには、`tegata.toml` の `idle_timeout` を秒単位で設定します。

```toml
[vault]
idle_timeout = 300 # 5分。0に設定すると無効
```

## 長いクレデンシャルリストのスクロール

クレデンシャルリストが表示可能な領域を超えると、サイドバーにスクロールインジケーターが表示されます。

```
│ │   Bitwarden          totp   │
│ │   ▲ 6 more above            │
│ │ > DB-backup          pw     │
│ │   Corp-LDAP          cr     │
```

サイドバーは詳細パネルとは独立してスクロールします。`↑` / `j` と `↓` / `k` を使用してスクロールします。選択されたクレデンシャルはサイドバーのスクロール位置に関係なく常に詳細パネルに表示されます。

## 日常的な使用のヒント

- **TUI を起動したままにする。** 作業セッション全体を通じて `tegata ui` を実行したままターミナルウィンドウを開いておきます。ボールトはアンロックされたままになり (アイドルタイムアウトに従います)、`Enter` キーを一度押すだけでコードを生成できます。
- **ボールトパスは不要です。** `TEGATA_VAULT` を設定すれば、TUI は自動的にボールトを見つけます。そうでない場合は、`tegata ui --vault /path/to/vault` を実行します。`/path/to/vault` を実際のボールトへのパスに置き換えてください。
- **スクリプト化には `tegata code` を優先する。** TUI はインタラクティブな使用向けです。自動化やシェルエイリアスには、直接 CLI を使用してください。

CLI コマンドの完全なドキュメントについては、[CLI リファレンス](cli-reference.mdx)を参照してください。
