Tegata（手形）は、標準的なUSBドライブまたはmicroSDカードに暗号化されたクレデンシャルを保存するオープンソースのポータブル認証システムです。名前は歴史的な日本の旅行証明書（手形）に由来しています。手形とは、手形の押印によってポータブルな身分証明として使用された文書のことです。タグラインは「あなたの認証履歴。整合性が確認された。」です。

## Tegataが解決する問題

多くの認証アプリは、クレデンシャルを特定のスマートフォンやクラウドアカウントに紐づけています。Tegataは、物理的に携帯しているハードウェアにクレデンシャルを保存します。これは、ハードウェアレベルの鍵の分離なしにポータビリティとオプションの監査可能性を必要とする個人にとって、専用のハードウェアセキュリティキー（YubiKeyなど）に代わる低コストの選択肢です。

## Tegataの機能

Tegataは4種類のクレデンシャルタイプをサポートしています。

- **TOTPおよびHOTP:** RFC 6238またはRFC 4226に準拠したサービスと互換性のある、時間ベースおよびカウンターベースのワンタイムパスワード
- **チャレンジ・レスポンス:** サポートするサービス向けのHMAC-SHA256署名
- **スタティックパスワード:** オンデマンドで取得する暗号化されたパスワード

クレデンシャルはUSBドライブ上のボールトファイルに保存され、選択したパスフレーズを使用してAES-256-GCMで暗号化されます。すべての認証はローカルで行われ、クラウドサービスへは何も送信されません。

## オプションの監査ログ

Tegataは、すべての認証イベントを[ScalarDL Ledger](https://scalardl.scalar-labs.com/docs/)によるバックエンドを持つ改ざん防止ハッシュチェーン監査ログに記録できます。監査ログはデフォルトで無効になっており、有効にするにはDockerが必要です。
